# Rust OS Learning Notes

This repository contains my personal learning notes while studying Rust, computer systems, and low-level programming with the long-term goal of understanding and developing an operating system.

## Purpose

My goal is not only to learn the Rust programming language, but also to understand the technologies that make modern computers work, including:

* Computer architecture
* CPU fundamentals
* Memory management
* Assembly language
* Concurrency and multithreading
* Networking
* Compilers
* Operating systems

This repository serves as a knowledge base where I organize what I learn along the way.

## Contents

The notes may cover topics such as:

* Rust language features
* Ownership and borrowing
* Lifetimes
* Concurrency (`Send`, `Sync`, threads, async/await)
* CPU and machine instructions
* Memory layout and management
* Assembly language
* Networking fundamentals
* Compiler design
* Operating system concepts

As my learning progresses, the structure and contents of this repository may change.

## Disclaimer

These notes are written primarily for my own learning.

Some explanations may be simplified, incomplete, or even incorrect. If you find mistakes or have suggestions, feel free to open an issue or submit a pull request.

## Progress

This is a long-term learning project.

The final goal is to gain enough knowledge and experience to understand how an operating system works internally and eventually build one myself.
